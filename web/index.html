sapf web by Victor Kashirin: github.com/victorkashirin/sapf-web

sapf (Sound As Pure Form) running in the browser via WebAssembly. A fork of ahihi/sapf, the cross-platform port of James McCartney's original lfnoise/sapf.

keys (Mod = Cmd/Ctrl)
Mod+Entereval line / selection
Shift+Entereval ( ) block
Mod+Shift+Entereval paragraph
Esc, Mod+.stop sound
Mod+Shift+.clear stack
Mod+Kclear console
Shift+Alt+Fformat
Ctrl+Spacecomplete (Mac: also Opt+` or Opt+I)
Mod+Ffind / replace
